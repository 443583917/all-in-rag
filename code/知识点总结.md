## 跨章节知识线总览

```
数据摄入    C1(UnstructuredLoader) → C2(partition/TextLoader/BiliBiliLoader)
    ↓
文本分块    C2(Character/Recursive/Semantic) → C3(SentenceWindow) → C8(MarkdownHeader) → C9(章节分块)
    ↓
向量嵌入    C1(bge-small) → C3(Visual-BGE多模态/BGE-M3) → C4(SigLIP) → C8/C9(bge-standard)
    ↓
向量存储    C1(InMemory) → C3(FAISS/Milvus/LlamaIndex local) → C4(Chroma) → C8(FAISS) → C9(Milvus)
    ↓
检索策略    C1(similarity_search) → C3(递归/窗口检索) → C4(混合RRF/元数据过滤/ColBERT重排/Text2SQL) → C8(FAISS+BM25 RRF) → C9(三路RRF+图键值+图邻居增强)
    ↓
路由分发    C4(LLM路由/嵌入路由) → C8(三分类路由) → C9(三策略智能路由+复杂度分析)
    ↓
生成回答    C1(PromptTemplate+invoke) → C5(Pydantic/FunctionCalling) → C8(LCEL chain/流式) → C9(自适应生成)
    ↓
编排框架    C1(LangChain手动→LlamaIndex黑盒→LangGraph显式图)
    ↓
评估反馈    C6(Faithfulness+Relevancy → BatchEvalRunner → 句子窗口vs常规对比)
    ↓
知识图谱    C9(Neo4j节点+关系 → 图RAG推理 → 多跳遍历 → 子图提取)
```
